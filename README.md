 WEBSITE NAME: MELI-NELE COMMUNITY CENTRE
Meli-Nele Community Centre Website

1. Project Overview

The Meli-Nele Community Centre website is a website designed to provide information about the organisation, its services, wellness programmes, and sustainable urban farming activities.

The website allows visitors to learn about the organisation, explore its services, read educational content, make enquiries, and contact the community centre.

3. Website Objectives

The objectives of the website are to:

* Introduce visitors to Meli-Nele Community Centre.
* Provide information about the organisation’s history and vision.
* Advertise community services and wellness programmes.
* Share nutrition, health, and urban farming tips.
* Allow visitors to enquire about services, products, volunteering, and sponsorship.
* Allow visitors to send general messages to the organisation.

4. Website Pages

The website contains the following pages:

* Home (index.html): Introduces the organisation and highlights its main activities.
* About (about.html): Provides information about the organisation, its history, and vision.
* Services (services.html): Describes the services and programmes offered.
* Learn (learn.html): Provides educational information about health, nutrition, and sustainable farming.
* Enquiry (enquiry.html): Allows visitors to submit enquiries about services, products, volunteering, and sponsorship.
* Contact (contact.html): Allows visitors to prepare a general message for the organisation.

5. Technologies Used

The website was developed using:

* HTML5: Structures the web pages and forms.
* CSS3: Controls the website’s appearance, layout, colours, and responsive design.
* Bootstrap 5: Supports responsive layouts and website components.
* JavaScript: Validates form input and prepares email messages.

6. Design and Layout

The website uses a modern and clean design with cream, green, and dark blue colours. It includes navigation links, headings, content sections, cards, forms, and a footer.

The layout is designed to work on desktop computers, tablets, and mobile devices.

7. Forms and Validation

The website includes two forms:

Enquiry Form: Collects the visitor’s name, email address, optional telephone number, enquiry type, and enquiry details.

Contact Form: Collects the visitor’s name, email address, optional telephone number, message type, and message.

JavaScript and HTML validation are used to check required fields and input formats. When a form is submitted, the visitor’s default email application is opened with the message prepared for sending.

8. How to Run the Website

1. Download or clone the project files.
2. Open the Meli-Nele-Website folder in Visual Studio Code.
3. Ensure that index.html, the other HTML pages, and the CSS folder are in the correct locations.
4. Open index.html in a web browser, or use the Live Server extension in Visual Studio Code.
5. Use the navigation menu to explore the website.

An internet connection is required for externally hosted resources, such as Bootstrap CDN files.
